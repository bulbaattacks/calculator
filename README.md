# calculator
Консольная утилита-калькулятор, которая принимает на вход два **целых числа типа `int`** и **операцию**, которую над ними нужно выполнить. Результат вычисления печатается в консоль. 

Допустимые операции: 
- сложение +, 
- вычитание -, 
- умножение *, 
- деление /, 
- возведение в степень, 
- факториал. 

math::Status math::division(int a, int b, int& result) 
если b > a получаем 0 тк инт - это ожидаемое поведение

math::Status math::multiplication(int a, int b, int& result)
экранируем \*
